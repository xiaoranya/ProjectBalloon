# 管理员指南

本指南面向比赛管理员，覆盖比赛管理：生命周期（含克隆与延长）、队伍与账号、题目与测试数据、员工账号与权限、公告、提交相似度审核、重判、审计日志、备份与归档。现场仪式工具见[现场运营指南](../onsite/README.md)。

## 比赛生命周期

比赛沿固定状态机流转：

```text
DRAFT -> FROZEN_CONFIG -> RUNNING <-> PAUSED -> ENDED -> ARCHIVED
```

- `DRAFT`（草稿）：构建题目、队伍与日程；对队伍不可见。
- `FROZEN_CONFIG`（配置冻结）：配置已锁定；开始比赛后进入进行中。
- `RUNNING`（进行中）：队伍可提交；支持暂停与恢复。
- `ENDED`（已结束）：判题排空并生成最终榜单。
- `ARCHIVED`（已归档）：比赛数据保留但不再活跃。

日程包含开始时间、封榜时间与结束时间。封榜时间冻结公共榜单，判题在后台继续进行。

### 克隆比赛

`SUPER_ADMIN` 可从比赛详情页克隆现有比赛：

- 克隆会复制题目配置（题号、展示顺序、颜色）。
- 是否复制当前队伍名单可选。
- 克隆以 `DRAFT` 状态创建；开始前需设置新日程。
- 需同时填写开始、封榜、结束三个日程字段，或全部留空；部分填写会被拒绝。

### 延长比赛

比赛处于 `RUNNING` 或 `PAUSED` 时，可从比赛详情页延长结束时间：

- 表单会预填比当前结束时间晚 30 分钟的新结束时间。
- 新结束时间必须晚于当前结束时间。
- 请求携带当前结束时间作为乐观并发检查；若比赛被并发修改，请重新加载后重试。

## 队伍与账号

- 可单独创建队伍，也可批量导入（1–100 行）。批量导入需要幂等键：用相同键重试会返回相同结果，而不是重复创建队伍。
- 导入的账号默认要求首次登录时修改密码；批量导入可按行覆盖该设置。
- 导入队伍会自动生成账号。请通过自己的渠道分发凭据。

### 重置队伍密码

在队伍管理区域，你可以重置队伍密码：

- 可选择是否要求队伍在下次登录时修改密码。
- 重置会撤销该队伍当前的活动会话；队伍需用新密码重新登录。
- 凭据丢失或需要重新验证队伍身份时使用此功能。

## 题目与测试数据

- 创建题目时可设置 slug、标题、题面（多语言）、判题模式（`STANDARD` 或 `INTERACTIVE`）、限制与可用语言。
- 题面以有界 Markdown 存储，并渲染为经过清理的 HTML。
- 附件与测试数据有版本：新上传会创建新版本；若题目被并发修改，编辑会被拒绝（乐观并发）。
- 测试数据上传为 ZIP 压缩包，规则如下：
  - 1 到 10,000 个条目，最大 256 MiB。
  - 测试用例必须是压缩包根目录下配对的 `.in`/`.out` 文件（不允许子目录）。
  - 拒绝路径穿越与重名文件。
- 封榜后拒绝修改题目与上传测试数据。

## 员工账号与权限

员工授权使用直接权限（而非角色）。权限码如下：

| 权限 | 授予的能力 |
| --- | --- |
| `CONTEST_MANAGE` | 创建/编辑比赛、队伍、题目、公告、重判 |
| `CLARIFICATION_MANAGE` | Clarification 工作台（`/judge`） |
| `PRINTING_MANAGE` | 打印工作台（`/printer`） |
| `BALLOON_MANAGE` | 气球任务（`/balloon`） |
| `RESOLVER_MANAGE` | Resolver 控制（`/resolver`） |
| `AWARD_MANAGE` | 颁奖管理（`/awards`） |
| `SCREEN_MANAGE` | 大屏管理（`/screen/manage`） |
| `LIVE_MANAGE` | 直播视图管理（`/live/manage`） |

`SUPER_ADMIN` 是用户类型而非角色：可以管理题库、练习平台设置与员工账号/权限。前端路由可见性不是授权边界；API 强制执行权限。

## 公告

在 `/admin/contests/:contestId/announcements` 管理公告：

- 创建公告后可立即发布，也可定时发布到未来时间。
- 可置顶公告，使其在选手的 Clarification 页面以及直播/大屏视图上更突出。
- 定时公告发布前可编辑或取消。
- 已发布公告可编辑或撤回；撤回后会从选手可见视图中移除。
- 公告状态：`SCHEDULED`、`PUBLISHED`、`WITHDRAWN`、`CANCELLED`。
- 已发布公告使用乐观并发；若公告被并发修改，请重新加载后重试。

## 榜单、快照与重判

- 提供公共/管理/分组/First Blood 榜单变体，支持 CSV 导出与快照。若榜单看起来过期，可从管理控制台重建缓存。
- 重判：批量重判接受 1–10,000 个提交 ID 与预期数量；之后请检查任务状态。
- 每个比赛可查看判题队列状态；结束比赛前排空 `PENDING`/`JUDGING` 工作。不要手动删除 outbox 行。

## 提交相似度审核

`SUPER_ADMIN` 可从比赛详情页审核跨队提交相似度：

- 设置最低相似度阈值（50–100%），并可选择按题目筛选。
- 扫描候选对；表格显示双方提交及其相似度百分比。
- 使用历史回填操作为该功能上线前的旧提交计算相似度。
- 相似度结果仅用于人工复核：不会自动处罚，也不会改变判题结果。

## 审计日志

`SUPER_ADMIN` 可在管理首页（`/admin`）查看审计日志：

- 可按操作人 ID、操作名称、结果（成功/失败）与时间范围筛选。
- 每条记录包含时间、操作、操作人、目标、来源 IP 与结果。
- 结果分页显示；使用筛选缩小调查范围。

## 比赛模式（终端绑定）

在 `competition` 部署模式下，选手在分配的工作站上用配对码登录，而不是使用账号密码。在 `/admin/competition`（需要 `CONTEST_MANAGE`）配置终端绑定：

1. 登记每个终端：静态 IP 地址、机位号与可选备注。
2. 加载目标比赛的绑定列表。
3. 把终端绑定到队伍。终端必须启用，且队伍必须在比赛名单中。
4. 配对码仅显示一次——请复制并交给对应机位，之后不会再显示。
5. 对每个机位重复以上步骤。

操作：

- **轮换配对码**：生成新码（仅显示一次）并立即使该绑定的现有会话失效。配对码泄露或排练结束后使用。
- **撤销**：解除终端绑定并立即使其会话失效；该机位需重新绑定后才能登录。

行为：

- 配对登录仅在恰好一个比赛处于进行中（`RUNNING`/`PAUSED` 且在日程范围内）时可用。
- 工作站会话绑定到终端 IP；来自其他 IP 的请求会被拒绝。
- 会话在比赛结束时失效。
- competition 模式会停用日常功能（题库、训练、练习、虚拟比赛与自助注册）。

## 练习平台

- `SUPER_ADMIN` 可配置练习设置：每日提交上限（默认 200）、并发判题上限（默认 3）与源码保留天数（默认 365）。
- 题解管理（`/admin/practice`，`SUPER_ADMIN`）：选择已发布题目与语言，编辑题解标题与 Markdown 内容。选择解锁规则——始终可见、首次提交后或通过后——并发布题解。

## 备份与归档

- 按[备份与恢复](../../ops/backup-restore.md)备份 PostgreSQL、对象存储与环境文件。
- 恢复需要显式确认 `PROJECT_BALLOON_RESTORE_ACK=I_UNDERSTAND_THIS_REPLACES_CURRENT_DATA`，并在正式比赛前完成恢复后验证。
- 归档比赛会关闭活跃生命周期；请按保留策略保留归档的备份。

## 正式比赛前

1. 导入队伍并验证凭据。
2. 上传测试数据并验证样例提交。
3. 冻结配置、做一次备份，然后才开始比赛。
4. 验证封榜时间、气球颜色、打印机与榜单缓存。
5. 比赛模式下，登记并绑定终端、分发配对码，并从测试机位验证配对码登录。
