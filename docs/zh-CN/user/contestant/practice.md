# 日常练习指南

本指南面向在正式比赛之外使用日常练习区的选手：公开题库、训练计划、练习提交、个人虚拟比赛与题解。日常练习区在标准部署模式下可用；`competition` 模式会停用该区域，改用工作站配对码登录（见[选手指南](./)）。

## 公开题库（`/problem-bank`）

题库列出已发布的练习题目。无需登录即可浏览：

- 按标签或难度筛选。
- 打开题目阅读题面与可用的语言。

## 训练计划（`/training`）

训练计划把题目组织成集合，包含必做与选做项：

- 浏览公开训练集，点击**加入训练**加入。
- 必做题目标记为**必做**，其余为选做。
- 每个训练集与每道题都会跟踪进度。

## 日常练习（`/practice`）

练习页是提交与跟踪练习记录的场所。需要先登录。

- 选择题目、语言并提交代码（与比赛相同的判题运行时：C、C++、Java 与 Python）。
- 使用收藏维护清单；可按全部、收藏或未通过筛选。
- 跟踪每道题的进度：尝试次数、最佳得分与是否通过。
- 提交记录显示每次练习提交及其判定详情（结果、时间、内存与判定版本）。

限制由管理员配置：每日提交上限（默认 200）与并发判题上限（默认 3）。若达到每日上限，请等到次日再提交。

## 虚拟比赛（`/practice/virtual`）

个人虚拟比赛让你可以按限时方式练习一组题目：

1. 新建虚拟赛，设置名称、时长并选择题目。
2. 在会话期间作答；提交会计入练习进度。
3. 会话结束后变为只读；可归档以保留结果，不再继续提交。

## 题解

- 每道题、每种语言可能有题解。
- 解锁规则由管理员设置：始终可见、首次提交后解锁或通过后解锁。
- 题解解锁后，可从练习页阅读。
