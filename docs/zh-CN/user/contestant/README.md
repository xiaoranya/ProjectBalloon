# 选手指南

本指南面向参加线上比赛的队员，介绍账号、提交代码、解读判定结果、查看榜单、提问 Clarification 与使用打印队列。

开始之前，请确保你有账号并能登录。账号通常由主办方导入，队长会收到凭据。

## 账号与登录

- 若启用了自助注册，可使用 `/register` 创建账号。
- 生成的账号可能要求在首次登录时修改密码。修改前只能访问认证流程。
- 登出或修改密码会撤销当前会话与其他会话；之后需要重新登录。
- 请保留浏览器会话 cookie；默认会话时长为 12 小时（`PROJECT_BALLOON_SESSION_TTL_SECONDS`）。

### 比赛模式（配对码登录）

在 `competition` 部署模式下，选手在分配的工作站上用配对码登录，而不是（或除账号密码外）使用账号密码：

1. 坐在分配的机位，打开 `/login`。
2. 选择**配对码**登录方式。
3. 输入主办方发给你所在机位的配对码。
4. 你将以本队身份登录当前进行中的比赛。

注意事项：

- 配对码仅对当前进行中的比赛有效，且只能从该工作站的静态 IP 使用。
- 会话绑定到该 IP；若请求来自其他 IP，会话会被拒绝，你必须回到分配的工作站重新登录。
- 会话在比赛结束时失效。
- 若工作人员轮换或撤销绑定，现有会话会立即失效，并会发放新的配对码。
- 同一页面仍可使用账号密码登录。

## 比赛页面

登录后，`/contests` 会列出你的队伍可以加入的比赛。进入比赛后可访问以下页面：

| 页面 | 路由 | 用途 |
| --- | --- | --- |
| 题目 | `/contests/:contestId/problems` | 题目列表与题面 |
| 提交 | `/contests/:contestId/submissions` | 提交代码并查看历史 |
| Clarification | `/contests/:contestId/clarifications` | 提问与阅读公告 |
| 打印 | `/contests/:contestId/printing` | 把代码发送到现场打印机 |
| 榜单 | `/contests/:contestId/scoreboard` | 实时排名 |

## 提交代码

1. 选择题目。
2. 选择语言。
3. 上传或粘贴源码文件。

支持语言为判题运行时镜像：C、C++、Java、Go、Rust 与 Python。

限流：每队每分钟最多 20 次提交；超限会返回限流错误，请稍候再试，不要反复提交。提交在队列中时状态为 `PENDING`/`JUDGING`，由 Worker 池处理；高峰期结果可能延迟。

### 解读判定结果

| 判定 | 含义 |
| --- | --- |
| `ACCEPTED` | 你的解法通过了全部测试用例 |
| `WRONG_ANSWER` | 输出与预期答案不一致 |
| `TIME_LIMIT_EXCEEDED` | 运行超过时限（Java 2 倍、Python 3 倍） |
| `MEMORY_LIMIT_EXCEEDED` | 超过内存限制 |
| `RUNTIME_ERROR` | 崩溃或异常退出 |
| `COMPILE_ERROR` | 源码未通过编译或语法检查 |
| `OUTPUT_LIMIT_EXCEEDED` | 输出超过输出限制 |
| `SYSTEM_ERROR` | 判题基础设施问题；请联系工作人员重判 |
| `CANCELLED` | 判定被取代或取消 |

比较器会在比较输出前规范化 CR/LF、行尾空格/制表符与行尾空行；其余内容按字节精确比较。

## 榜单与封榜

- 公共榜单按通过题数、再按罚时排名。
- 封榜期间（`freeze_at` 之后），公共榜单隐藏封榜后的提交。你自己的提交与管理端榜单仍显示真实状态。
- 比赛结束后公共榜单保持封榜；不会自动揭示隐藏提交。
- First Blood 针对正式、非明星队伍按题目记录，并显示在榜单与直播视图上。

## Clarification

- 在 Clarification 页面提问关于题目或比赛的问题。
- 公共公告也会列在那里。
- 限流：每队每 5 分钟 1 条 Clarification。
- 工作人员可以私密回复、把问题转为公共公告或关闭问题。回复会出现在你的 Clarification 页面。

## 打印（现场比赛）

打印页面可把源码发送到现场打印机。

- 限制：单次请求最多 20 KiB 内容与 5 页；每队每 10 分钟 1 次；每队整场比赛最多 20 次。
- 通过状态（`QUEUED`、`PRINTING`、`DONE`、`FAILED`）跟踪请求。任务失败时，请联系打印台重试。

## 日常练习

在正式比赛之外，平台可能提供日常练习区：公开题库、训练计划、练习提交、个人虚拟比赛与题解。使用方法见[日常练习指南](practice.md)。

## 个人资料

使用 `/profile` 查看队伍与成员信息，使用 `/change-password` 修改密码。修改密码后，请用新密码重新登录。
