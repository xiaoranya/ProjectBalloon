# 使用手册

使用手册面向通过 Web 界面使用 ProjectBalloon 的人，无需阅读后端源码：选手、比赛管理员和现场运营人员（大屏、直播、气球、打印、Resolver 与颁奖）。

这些指南假设[快速开始](../ops/quickstart.md)描述的部署正在运行。配置与环境变量参考见[配置参考](../ops/configuration.md)；常见故障排查见[故障排查](../ops/troubleshooting.md)。

## 章节

- [选手指南](contestant/README.md) — 注册与登录、提交代码、解读判定结果、榜单与封榜规则、Clarification 与打印。
- [管理员指南](admin/README.md) — 比赛、队伍、题目、员工账号与权限、重判、备份与归档。
- [现场运营指南](onsite/README.md) — 大屏、直播、气球、打印工作台、Resolver 仪式与颁奖展示。

## 语言

英文版本位于 `user/`；中文镜像位于 `zh-CN/user/`，内容一致。代码块、命令、路由与权限码在两种语言中都保持英文。
