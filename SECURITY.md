# Security policy

Please do not report security vulnerabilities in public issues. Send a private
report to the repository maintainers with a description, reproduction steps,
affected version, and any suggested mitigation. Do not include production
credentials or personal data in the report.

The project is intended for fresh deployments. Review `.env.example` and the
operations documentation before exposing an instance to a network, rotate all
bootstrap secrets, and keep dependencies and container images current.
