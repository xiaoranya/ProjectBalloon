### A2. 前端

1. **组件抽取**(LiveView 现状是单文件渲染全部内容):抽出 `components/live/` 下的 `LiveHeader`、`LiveScoreboard`、`LiveMetrics`、`LiveHero`(一血/冻榜倒计时)、`LiveTicker`、`LiveClock`,LiveView 改为复用,现有 `/live/*` 五条路由行为不变(现有 `LiveView.test.ts` 回归保障)。
2. **First Blood 动画(关闭 P1 缺口)**:新组件 `LiveFirstBloodPopup.vue` — watch 首杀队伍/题目变化时触发入场动画(CSS keyframes:缩放+发光+粒子迸发,零依赖),并常驻轻微呼吸动效;同时应用于 `/live/first-blood` hero 与 `/live/program` 弹窗层;带 `prefers-reduced-motion` 降级。
3. **合成主画面 `/live/program`**(公开路由,`#token=` 鉴权,与 LiveView 同模式):固定层级 = 舞台(当前场景)+ 底部公告条 + 时钟 + 一血弹窗层;通过 `subscribeContestEvents`(PUBLIC SSE)监听 `LIVE_PROGRAM_UPDATED` 即时切场景,断线走既有 10s 轮询兜底;场景切换用 `<Transition>`(时长取自 `transitionMilliseconds`)。RESOLVER/AWARDS 场景复用 resolver/awards 的公开 API —— 将 `ResolverDisplayView`/`AwardDisplayView` 的舞台内容抽成 `ResolverStage.vue`/`AwardStage.vue` 供合成页复用;RESOLVER 场景的 run 来源 = program 状态里的 `resolverRunId`,为空时取最新可展示 run(resolver 公开接口已有列表端点)。
4. **叠加层 `/live/overlay`**(公开,透明背景):OBS 上层浏览器源,渲染公告条+一血弹窗+时钟,`?parts=ticker,popup,clock` 选择子元素;全局样式 `html,body{background:transparent}`。
5. **导播台 `/live/program/control`**(路由 meta:`requiresAuth+requiresStaff+LIVE_MANAGE`):8 个场景按钮、RESOLVER run 选择、转场时长/时钟/公告条开关、`expectedVersion` PUT(409 时重取重放)、键盘快捷键(1–8 场景、T 公告条、C 时钟)、一键生成合成页/叠加层带 Token 链接、"正在播出"指示。
